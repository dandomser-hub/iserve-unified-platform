# Administration and Security Management

Owns authenticated staff sessions, approved role/permission seeding, backend
permission gates, record-scope enforcement contracts, account lockout, privacy
controls, audit review, backup metadata, and security administration.

P1-02 deliberately does not grant System Administrators approval authority
over official barangay documents, KP actions, DRRM submissions, GAD
submissions, or collection certification. Those authorities remain with the
approved business roles. Administration never inherits sensitive case access.

No production user or shared credential is seeded.
