# Barangay iSERVE Unified Platform Documentation

This documentation tree is the controlled artifact home for the broader Barangay iSERVE Unified Platform program.

## Workstreams

- `00-program` — program governance, roadmap, decisions, portfolio and release evidence
- `01-shared-platform` — Unified Dashboard, identity/SSO, shared data and platform services
- `02-drrm` — iSERVE DRRM
- `03-gad` — iSERVE GAD
- `04-governance` — iSERVE Barangay Governance and its subsystems
- `05-citizens` — iSERVE Citizens
- `06-integration` — cross-system integration and service contracts
- `07-security-privacy` — shared security, privacy and data-governance controls
- `08-deployment` — deployment, DevOps and operational-readiness artifacts
- `99-legacy-reference` — controlled index to preserved legacy Barangay iSERVE baselines

## Standard subfolders

System workstreams use `system-analysis`, `system-architecture`, `diagrams`, `backlog`, `decisions`, and `release-evidence` as controlled artifact categories.

Initial artifacts are committed as **Draft for Review and Approval**. Approved documents remain current until explicitly superseded through controlled versioning.
