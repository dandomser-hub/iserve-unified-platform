# 05 — iSERVE Citizens

Fourth-priority system workstream for citizen accounts, resident linkage, service catalog, requests and tracking, public DRRM information, public GAD information, participation, feedback, notifications and document verification.

Citizen access remains purpose-limited and must never provide general access to internal resident, case, operational, asset or draft-report data.

Standard categories: `system-analysis`, `system-architecture`, `diagrams`, `backlog`, `decisions`, and `release-evidence`.
